# Getting Started

Boppa is a native audio player for anything you already stream. Everything it can search,
browse, and play comes from a **media source**, a small package you add yourself.

## Add your first media source

Check out [r/BoppaApp](https://reddit.com/r/BoppaApp) to find a media source.

Once you have a package URL, open **Settings → Media Sources → Add Source** and paste it in.
You can also pick a `.boppa` or `.zip` file stored on your device. Boppa downloads the package,
validates it, starts it up, and adds the media source to your app.

## Creating your own media source

If you just want to listen, that's it, you're set. If you'd rather build your own media
source instead of using one from the community, see [Media Sources](/docs/media-sources)
for how a package is put together.
