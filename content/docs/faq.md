# FAQ

## Is Boppa free?

Yes, core functionality of Boppa is free.

## Does Boppa host any audio itself?

No. Boppa has no built-in catalog. Every source of audio comes from a media source
you add yourself.

## Can I write my own media source?

Yes, that's the intended way to extend Boppa. See [Media Sources](/docs/media-sources)
for how a media source package is put together.

## Is there an Android or desktop version?

Not currently. Boppa is iOS-only today.
